# 👋 Hi, I’m Yuuki  
**Backend / Python Developer**

Python‑бэкенд‑разработчик, который пишет **масштабируемые сервисы и REST API** для e‑commerce, аналитики и внутренних систем. В работе редко гонюсь за «модной» архитектурой, больше ценю **простоту, читаемость** и сервис, который стабильно работает в проде и не требует аду в аду.

🔧 **Что я делаю**  
- Разрабатываю backend‑сервисы и API на **FastAPI** с PostgreSQL, Redis и Celery: от первых прототипов до продакшн‑развёртывания.  
- Пишу **Telegram‑ботов и системы мониторинга** — от отслеживания LNG‑судов в морских зонах до управления VLESS‑клиентами 3X‑UI, собираю данные и генерирую датасеты для дальнейшего анализа.  
- Строю и поддерживал e‑commerce, фриланс‑платформы и аналитические сервисы: управление товарами, заказами, пользователями, услугами и навыками, с JWT‑аутентификацией, фоновыми задачами и кэшированием.  
- Реализую **интеграции с внешними API и вебхуками**: Meta, Shopify, BigCommerce, Sendlane и другими сервисами, занимался синхронизацией данных и обработкой событий через фоновые Celery‑воркеры.  
- Оптимизирую производительность: добавляю кэширование в Redis, улучшаю структуру запросов, выношу тяжелые операции в background, включаю rate limiting и логирование для отладки.
